# Политика конфиденциальности КосмоКода

Версия приложения: 1.0.0. Правообладатель: Виктория Пенчук. Политика описывает поведение Android-приложения, проверенное по его исходному коду и манифесту.

## Какие данные обрабатывает приложение

КосмоКод не запрашивает имя, телефон, адрес электронной почты или учетную запись. В приложении нет рекламы и сторонних аналитических трекеров. Игровые звезды, достижения, настройки, прохождение, результаты и сведения о дипломе сохраняются локально в хранилище приложения на устройстве. Приложение не отправляет игровой прогресс на сервер и не передает персональные данные разработчику.

В приложении не обнаружены серверные API-вызовы для передачи игровых данных. Код загружает файлы приложения и юридические документы с локального адреса приложения. Разрешение Android `INTERNET` объявлено для WebView; само по себе наличие разрешения не означает отправку данных. Android-резервное копирование данных приложения отключено.

## Системная озвучка

Озвучка необязательна. В Android-версии приложение передает системной службе Android TextToSpeech короткие фразы с названиями команд игры и цветов. Приложение не выбирает поставщика голоса и не может определить, обрабатывает ли конкретный установленный TTS-движок речь локально или отправляет текст своему поставщику для обработки. Если движок использует сетевую обработку, поставщик может получить эти фразы согласно своим правилам. Не вводите в приложение персональные сведения для озвучивания: приложение не предназначено для этого.

В веб-версии синтез речи может выполнять голосовой движок браузера; его обработка зависит от браузера и выбранного голоса.

## Срок хранения и удаление

Локальные данные приложения можно удалить средствами Android через «Настройки → Приложения → КосмоКод → Память → Очистить данные» либо удалив приложение. Это удаляет локальное хранилище приложения. Отдельно сохраненный пользователем PNG-файл диплома хранится вне хранилища приложения и при очистке данных или удалении приложения может остаться на устройстве; его нужно удалить отдельно в приложении «Файлы».

Встроенная функция «Сбросить весь прогресс» очищает открытые уровни, результаты и звезды, достижения всех игр и обучение. Она сохраняет настройки звука, озвучки, скорости, темы и режима управления, а также статус уже полученного диплома выпускника. Поэтому диплом остается доступен, но число звезд в новом файле диплома после сброса может стать нулевым. Копия диплома, которую пользователь уже сохранил как PNG, не удаляется.

В манифесте приложения установлено `android:allowBackup="false"`, чтобы отключить системное облачное резервное копирование. Android указывает, что на устройствах некоторых производителей эта настройка может не запрещать прямой перенос данных между устройствами. Поэтому приложение не обещает, что такой перенос исключен на любом устройстве; его поведение может зависеть от производителя и версии Android. Приложение также не может удалить копии данных, которые могли быть созданы платформой до отключения резервного копирования. [Документация Android о резервировании и переносе данных](https://developer.android.com/about/versions/12/behavior-changes-12).

## Сторонние сервисы

Приложение не отправляет данные разработчику. Системный TTS-движок и голосовые службы браузера являются отдельными компонентами платформы; их поставщики обрабатывают данные по своим правилам. При переходе по внешней ссылке применяются правила соответствующего сайта.
